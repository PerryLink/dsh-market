# PerryLink DSH plugins index

A [DSH plugin market index](https://github.com/deepseek-ai/deepseek-harness/blob/main/docs/user/guide/plugin-market.zh.md) in format `1` for the PerryLink DeepSeek Harness plugin family.

## Add it to DSH

1. Open **Plugins → Experimental → Custom plugin index** and enable it.
2. Open **Plugins → Discover → Add index source**.
3. Enter:

```text
https://perrylink.github.io/dsh-market/index.json
```

If GitHub Pages is unreachable from your network, the jsDelivr mirror serves the same file:

```text
https://cdn.jsdelivr.net/gh/PerryLink/dsh-market@main/index.json
```

The file is UTF-8 JSON, served over HTTPS without a redirect, and every icon is an inline `data:` URL, so a Git source works as well:

```text
git+https://github.com/PerryLink/dsh-market.git
```

## What it contains

- Active and frozen PerryLink plugins published on npm.
- Retired plugins and obsolete migration corridors are excluded.
- Bilingual titles and descriptions (`en` + `zh`), inline icons, author, repository, homepage, keywords, and a category from the declared hub set.
- Versions, timestamps, npm sources, and `engines.dsh` come from the official reference generator's npm data; the display fields are curated from each package's locale metadata and the family catalog.

## Trust

This is a third-party index. DSH validates the file format and shows the exact npm source before installing, but it does not verify titles, icons, or authorship. Pin a commit or review the change history if you need reproducibility.

## Regenerate

The index is generated by the official `@deepseek-ai/dsh-plugin-market-generator` from the package list, then enriched with the family catalog:

```sh
# in a DeepSeek Harness checkout
pnpm --filter @deepseek-ai/dsh-plugin-market-generator start \
  --input sources.txt --output market/index.json --title "PerryLink DSH plugins" \
  --inline-icon-bytes 32768
node build-dsh-index.mjs market/index.json index.json
```

Every entry is validated with `parseMarketIndex` for both an HTTPS source and a `git+https` source before publishing.
